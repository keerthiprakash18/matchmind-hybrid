# MatchMind | 3-minute English video storyboard

**00:00–00:20 — The problem.** Grassroots coaches have incomplete notes and unstable connectivity. Show the interface and clearly state the demo match is fictional.

**00:20–00:50 — Record evidence.** Log a realistic pressure or overload event, and show the recorded-event trend chart. Clarify these are manual observations, not tracked match telemetry.

**00:50–01:30 — Cloud AI.** Select Cloud and request a halftime briefing. Show a real Firebase AI Logic response with cited observation minutes; do not fabricate model output.

**01:30–02:15 — On-device proof.** On supported Chrome Desktop with Gemini Nano downloaded, select On-device and show an actual response. A visible SDK `ON_DEVICE` source label or equivalent external proof is required. If unsupported, explicitly disclose rather than stage it.

**02:15–02:40 — Hybrid fallback.** Demonstrate the preferred route and actual fallback, separately confirming the reported source. Explain what happens without local model support.

**02:40–03:00 — Safety and impact.** Show privacy disclosure, export brief, no invented player stats, and how a coach makes the final decision.

Before recording: hide DevTools secrets, reCAPTCHA debug tokens and any private account data. Disable debug mode for published app and use a dedicated demo Firebase project.
