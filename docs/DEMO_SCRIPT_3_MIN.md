## Production and judging quality gate
- Film with **1920×1080 capture at 30fps**; crop Chrome tab bar before showing personal data. Test with captions.
- Avoid fake scores, fabricated usage numbers, unrelated trademarks, stock sports clips with unclear licensing, and any Firebase App Check debug token.
- Replace all placeholder URLs before publishing. Use a public, searchable YouTube link.
- Make source repository public with its open-source license; show the real app working through the final build.
- Audio, graphics and captions should be original or properly licensed. Keep cuts natural, avoid false continuous-real-time claims.
- Check final duration, spelling, mobile readability, no popups/notification leaks, secure hosted link, and actual GitHub state.
